## Lessons Learned
- How to use Git to track and manage changes.
- How to create branches and switch between them.
- How to commit and push changes to GitHub.
- How to create pull requests and review code.
- How to identify and resolve merge conflicts.
- How to collaborate with other developers using GitHub.
- The importance of writing clear commit messages and maintaining project documentation.

## Challenges Faced
- Understanding the difference between local and remote repositories.
- Managing branches and keeping them synchronized.
- Resolving merge conflicts when changes affect the same lines.
- Learning how to review and merge pull requests correctly.

These challenges are addressed through practical exercises, careful use of Git commands, and collaboration with other developers.
